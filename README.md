Pid sim for a wing.

Project Files:
index.html: Structure of the simulator.
style.css: Styling and layout.
script.js: Simulation logic, wing movement, and PID control.

How to Run:
Download or clone this repository.
Open the project folder in VS Code.
Open index.html in a web browser.

Features:
Manual and automatic control modes.
PID-based feedback control.
Adjustable pressure and target wing angle.
Simulated actuator response and sensor noise.
Disturbance simulation.
Real-time graphs showing target, actual, and measured wing angles.
Simulated flapping mode.

You can modify the source files to experiment with different control parameters, actuator behaviour, sensor noise, and wing movement so feel free to download, explore, and build upon the project.
